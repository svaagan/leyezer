# Leyezer – nettsiden

Personvern og hjelp for iPhone-spillet Leyezer, servert av GitHub Pages fra repoet
`svaagan/leyezer`. Statiske filer, ingen byggsteg.

- `index.html` – forsiden.
- `personvern/` – personvernerklæringen. Adressen står i App Store Connect.
- `support/` – hjelp. Blir Support-URL i App Store Connect.
- Alle lenker er relative, så sidene virker både under `svaagan.github.io/leyezer/` og på et eget domene senere.

Kilden til appen ligger i et eget, privat repo.
